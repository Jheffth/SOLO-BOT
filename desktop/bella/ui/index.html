Conversa

Neste modo, mensagens livres vão para a conversa pessoal. Para os sistemas, use /fin, /rot ou desligue o modo. Pedidos de abrir pastas e usar o Word continuam disponíveis. Cada pedido é independente, sem histórico de conversa.

Escuta

O tempo das etapas do último pedido aparecerá aqui.

Frases de ativação: cadastre de uma a três. Diga a frase completa e faça uma pausa. Quando aparecer “Pode falar”, faça o pedido. Prefira frases com duas ou mais palavras.

A chamada é reconhecida neste computador. Os campos vazios são ignorados. No modo apertar para falar, somente a tecla ativa a gravação.

Segure até aparecer “Pode falar”. Continue segurando enquanto fala e solte para enviar. Se soltar antes do tempo, nada será gravado. Funciona também com a janela fechada.
